# TeamSync AI — HTML, CSS and JavaScript Website

## Files
- `index.html` — page structure and modules
- `style.css` — responsive layout and styling
- `script.js` — interactive matching, budget, tasks, finalization, and feedback

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** extension in VS Code.
4. If using Live Server, right-click `index.html` and choose **Open with Live Server**.

No Python or npm installation is required for this front-end demo.

## Important limitations
This version is a front-end prototype. It uses sample data held in JavaScript memory. Refreshing the browser resets edits; it does not yet have a database, user accounts, real multi-user collaboration, or a trained AI model. Matching is a simple, explainable skill-coverage score with a small interest bonus. A backend and database are needed to persist data and support multiple students.
